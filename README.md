# NotiRoute

A free audio mixer for macOS by noticode. Combine microphones and selected applications into virtual stereo inputs.

**Website and downloads:** https://borzycki.dev/projects/notiroute

Requires macOS 14.5 or later and an Apple silicon Mac. English and Polish interface.

Release files are hosted here; this repository does not contain the application source code. The first installer is being prepared.

## Installation

Download a published DMG through the product website, open it and drag NotiRoute to Applications. Configure the audio component in the app’s Settings. This requires administrator permission and briefly interrupts system audio.

## Updates

Download the latest DMG, quit NotiRoute and replace it in Applications. Saved mixes remain on your Mac. Update the audio component in Settings if prompted. Updates are currently installed manually.

Published releases contain a versioned DMG, an identical `NotiRoute-latest-arm64.dmg`, and `SHA256SUMS.txt`.
